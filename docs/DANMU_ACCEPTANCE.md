## 各平台真实数据

下表耗时为本次客户端 HTTPS 取弹幕的一次实测，不代表长期性能承诺。数量是原始 XML 条目数；播放器默认过滤/限制为最多 5,000 条。

| 平台 | 测试节目 | 搜索与选集 | 弹幕数 | 弹幕请求耗时 |
|---|---|---|---:|---:|
| 腾讯 | 三体，2023，第1集 | 成功，ep 10050 | 43,538 | 7.11秒 |
| 腾讯 | 三体，2023，第2集 | 成功，ep 10051；经 Moon 代理 | 46,985 | 9.82秒 |
| 爱奇艺 | 狂飙，第1集 | 成功，39集列表 | 17,701 | 8.47秒 |
| 优酷 | 甄嬛传，第1集 | 成功，76集列表 | 15,300 | 16.21秒 |
| 芒果 | 去有风的地方，第1集 | 360搜索条目 → imgo，40集列表 | 12,205 | 4.76秒 |
| Bilibili | 我的三体第四季，第1集 | 成功，9集列表 | 3,904 | 2.65秒 |
| 弹弹Play | 三体，2022动画，第1集 | 成功，15集列表 | 10,556 | 2.48秒 |

搜索实测：三体约9.86秒、狂飙9.09秒（含豆瓣超时阶段）；甄嬛传4.08秒；去有风的地方2.72秒。移除反复超时的豆瓣后，Moon 代理搜索三体约5.05秒，返回21项。搜索结果与真实弹幕来源分别记录，芒果没有把“仅查到条目”当作成功，而是进一步获取并解析了 XML。

原生匹配 `三体 S01E01 @qq`、`三体 S01E02 @qq` 分别返回腾讯第1/2集 URL，shift=0。Moon 代理搜索、剧集列表、匹配及评论接口均已实测。最终分集过滤后的腾讯列表为30集，排除了附加内容。

## 浏览器验收

- 首先用获授权的 W3C Sintel 片段验证真实外部弹幕显示、关闭、重新开启、手动第1/2集切换。该组合仅验证渲染链路，不用于证明内容一致。
- 随后使用站点已有影视源搜索三体（69个现有源、36组聚合结果）。未新增或修改影视源。
- 普通《三体》播放页自动搜索并弹出9个匹配弹幕源。首次有多版本候选时需要选择一次，不能称为完全无交互。
- 选择腾讯2023电视剧版本后，第1集视频播放并显示对应真实弹幕；页面显示原始43,538条，播放器加载5,000条。
- 第1集切换到第2集时，播放器自动加载对应46,985条原始弹幕（显示上限5,000），视频播放至01:04；不需要再次搜索选源。
- 时间轴会随视频进度显示弹幕。第三方视频线路可能含片头插入或不同剪辑，未完成全片逐句时间同步校准；必要时手动偏移或选择对应版本。
- 短暂停止仅本项目 API 后，新搜索报错，已播放视频从00:05继续到00:19，未被中断；预设自动恢复并提前手动恢复，健康复核通过。
- `/tv` 已正常打开并显示电视首页。电视播放器复用弹幕网络模块，使用独立渲染器；未验证实体电视/遥控器上的完整弹幕流程。
- 直链播放模式上游明确跳过自动搜索，需手动选择弹幕；普通有标题/集数的剧集播放才执行自动匹配。

## 修复与发布

- Cloudflare 区级 Flexible 曾导致 Worker 同区子请求循环重定向。已仅对 `danmu.vafa.eu.org/*` 设置严格 TLS，原区级设置不变。
- 上游弹幕代理原始异常会回显含查询 Token 的 URL。已将4个代理的异常日志改为固定文案，搜索/匹配/剧集错误响应不再回显原始异常，并轮换查询 Token。故障测试验证响应不包含新密钥。
- `/api/server-config` 不包含查询 Token，仅提供自动加载开关等客户端设置。
- GitHub Actions 发布成功：[修复与部署记录](https://github.com/JackyHoSZ/MoonTVPlus/actions/runs/38506296416)，提交 `5c4676c`。TypeScript 检查通过。
- 管理后台4项弹幕设置已保存回读；其他配置保持。配置更改后上游 Worker 进程缓存可能保留旧值，因此 Token 轮换后已重新发布。

## 尚未覆盖与使用边界

无平台登录、验证码或付费访问绕过；豆瓣搜索源因超时移除。咪咕本次仅验证搜索结果，未验证其弹幕。多源合并、统一时间偏移、本地 XML 上传、完整电影和全片时间校准未实测，不宣称通过。实体电视弹幕与跨版本镜像回滚仍需相应设备/升级版本才能验证。
